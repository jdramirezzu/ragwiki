# Intro video

The finished videos, with music and narration: [`media/ragwiki-intro-en.mp4`](media/ragwiki-intro-en.mp4) and [`media/ragwiki-intro-es.mp4`](media/ragwiki-intro-es.mp4).

The intro video is generated by code, so anyone can update it when the lab changes.

| File | Role |
|---|---|
| `capture.py` | Takes screenshots of a running lab (`uv run ragwiki lab`) with Playwright and Chrome |
| `shots/` | The screenshots used in the video: a real run on five public arXiv papers about LLM wikis, answered by `deepseek-flash` |
| `video.html` | The animation. `render(t)` draws the frame at second `t`, so every frame is deterministic; `?lang=es` or `?lang=en` |
| `still.py` | Saves single frames, to check the layout |
| `record.py` | Renders every frame with Chrome and encodes an MP4 with ffmpeg |
| `narration.md` | The voice-over script in Spanish and English, one short clip per scene, with its timing |
| `music.py` | Generates the background music from sine waves: original and license-free |
| `mix.py` | Adds the music and, once recorded, the narration clips; lowers the music while the voice speaks |

```bash
uv run --no-project --with playwright --with imageio-ffmpeg python docs/video/record.py en ragwiki-intro-en.mp4
```

The numbers on screen come from that run (5 papers, 184 paragraphs, a 24-page wiki built
for $0.11, 7 compared questions) and from the study behind ragwiki.
