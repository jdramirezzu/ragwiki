# Narration script

Record one short clip per scene, in a quiet room, about 20 cm from the microphone. Name
the files `s01` to `s13` (any audio format: `.wav`, `.m4a`, `.mp3`, `.ogg`) and put each
language in its own folder. `mix.py` places every clip at the start of its scene, lowers the
music while you speak and warns when a clip is longer than its window.

Speak calmly: each line fits its window at a relaxed pace, with a breath to spare. If a
clip goes over, say it a little faster or drop a word; nothing needs to match the screen
word for word.

## Mixing

```bash
# Music only (no voice yet)
uv run --no-project --with numpy --with imageio-ffmpeg python docs/video/mix.py \
  --video ragwiki-intro-es.mp4 --out ragwiki-intro-es-music.mp4

# Music and voice
uv run --no-project --with numpy --with imageio-ffmpeg python docs/video/mix.py \
  --video ragwiki-intro-es.mp4 --voice voice/es --out ragwiki-intro-es-final.mp4
```

The music is generated by `music.py` from sine waves, so it carries no license beyond this
repository's.
