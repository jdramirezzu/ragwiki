# Example notes

Small sets of notes written for this project, so anyone can try wikinotes without using
their own material. They are released under the same MIT license as the code.

| Folder | What it holds | Try asking |
|---|---|---|
| `cell-biology/` | Three short lecture notes: the cell, cellular respiration, photosynthesis | See the [walkthrough](../docs/demo.md) |

Add your own set with a pull request. Use only material you wrote or that has an open
license, and say which one.
